# Telegram bot and web chat

Two ways to use R2 Copilot without installing anything: the **Telegram bot** and the **web chat**. Both are for the quick question you have when you are not inside a document — the same assistant, reached from the device in your hand.

## Telegram bot

Open [`@R2Copilot_bot`](https://t.me/R2Copilot_bot) and start a conversation. Useful when a draft or an answer is needed away from the desk, without opening Outlook.

## Web chat

Open [chat.r2copilot.ai](https://chat.r2copilot.ai/) and sign in. A browser tab, no install, the same account.

## Which to use when

| You are | Use |
|---|---|
| In an Office document or a mailbox | The [add-in](../availability.md) |
| Reading or writing in a browser tab | The [Chrome extension](./chrome-extension.md) |
| Away from the desk | The Telegram bot |
| On a machine where you cannot install anything | The web chat |

All of them run on the same subscription and the same monthly pool of prompts and tokens. See [Plans and pricing](../pricing.md).
