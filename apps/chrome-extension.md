# R2 Copilot Chrome extension

The Chrome extension puts R2 Copilot in a side panel beside whatever page you have open. It keeps per-site context, can answer about the page itself, and inserts what it writes straight into a Gmail or Outlook draft — without switching tabs.

**Get it:** Chrome Web Store, extension `lnemoinjpddcpipmnjinebibnpfhdnan`, published by r2copilot.ai. Rated 5.0 out of 5 across 28 ratings.

## What it does

- **Side panel on any page.** The assistant opens alongside the active page rather than replacing it.
- **Page-aware chat.** Ask about what is on screen instead of copying text out of it.
- **Per-site context.** The panel keeps context for the site you are on.
- **One-click insert.** Push a draft into Gmail or Outlook without leaving the page.

## When to use the extension instead of an add-in

Use the **add-in** when the work lives in an Office document — a long report, a spreadsheet, a mailbox. Use the **extension** when the work lives in a browser: a web mail client, an internal tool, a page you are reading and want summarised.
